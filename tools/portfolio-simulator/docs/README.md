## คู่มือฉบับปัจจุบันมีอะไร

ส่วนที่ 1–6 เป็นคู่มือใช้งาน (ทำความเข้าใจก่อนเริ่ม · เริ่มใช้ใน 5 นาที ·
ความหมายของทุกช่องกรอก · วิธีอ่านผลลัพธ์ · บันทึก/เปิดเคสและรายงาน PDF ·
ข้อผิดพลาดที่พบบ่อย) และภาคผนวก ก–ฏ อธิบายหลักการคำนวณเบื้องหลัง

**สิ่งที่เพิ่มจากเล่ม 1.4.0** คือทุกอย่างที่เครื่องมือได้มาในรุ่น 1.5.0–1.7.0 — และรอบนี้
**หน้าจอเปลี่ยนไปพอสมควร** ไม่ใช่แค่เพิ่มหัวข้อ:

- **ปุ่มสลับหน่วยเงินทั้งหน้า** ระหว่างมูลค่าปัจจุบันกับมูลค่าในอนาคต (หัวข้อ 4.1 ใหม่ทั้งหัวข้อ) —
  เรื่องนี้สำคัญกับการอ่านตัวเลขทุกตัวบนหน้า จึงถูกยกขึ้นเป็นหัวข้อแรกของส่วนที่ 4
- **โหมดถอนที่สี่ "% ของพอร์ต"** (หัวข้อ 3.2) และ **ตัวเลขความอยู่รอดนิยามที่สอง**
  ที่ใช้เฉพาะโหมดนั้น (หัวข้อ 4.2 และภาคผนวก ฉ.) — คู่มืออธิบายไว้ว่าทำไมโหมดนี้
  ถึงทำให้เกณฑ์ "เหลือมากกว่า 0" ตอบ 100% เสมอ และทำไมจึงต้องเปลี่ยนคำถาม
- **การ์ดกระแสเงินสดกลายเป็นตารางที่พับเก็บได้** (หัวข้อ 4.6)
- **แถบเตือนเหนือ Heatmap** เมื่อโหมดบนหน้าหลักกับกติกาของตารางไม่ตรงกัน (หัวข้อ 4.7)
- **สมมติฐานวินัย DCA** — ทุกตัวเลขตั้งอยู่บนการเติมเงินครบทุกงวดแม้ในปีที่ตลาดพัง (หัวข้อ 3.6)
- ชื่อเรียกที่ถูกแก้ให้ตรงกับสิ่งที่วัดจริง: "กระแสเงินสดเฉลี่ย" → **"Median ของ Cashflow"** ·
  "ถอนสะสมรวม" → **"Cashflow สะสม"** · ชื่อโหมดถอนทั้งหมด

**เส้นแบ่งการเปิดเผยที่ตกลงไว้ ยังเหมือนเดิมทุกข้อ:** เปิดเผย *หลักการ* ทั้งหมด —
Monte Carlo, วิธีจำลองสามแบบ, ลำดับการทำงานของ Global Waterfall ในแต่ละเดือน,
แนวคิดสหสัมพันธ์และการกระจายความเสี่ยง, Efficient Frontier, วิธีวัด Max Drawdown,
ขั้นตอนของ VaR และวิธีนับตัวเลขความอยู่รอดทั้งสองนิยาม — แต่ **ไม่เปิดค่าตัวเลขในตาราง
สหสัมพันธ์ ไม่เปิดเกณฑ์แบ่งกลุ่มสินทรัพย์ และไม่มีสูตร** (ภาคผนวก ช. จึงเขียนว่า
"คูณด้วยตัวคูณทางสถิติของระดับความเชื่อมั่น 95%" โดยไม่ระบุค่าตัวคูณ)

ภาคผนวก ฎ. (*สิ่งที่แบบจำลองนี้ไม่ได้รวมไว้*) ยังเป็นหัวข้อที่สำคัญที่สุดของเล่ม —
ภาษี ค่าธรรมเนียม ค่าซื้อขายตอนปรับสมดุล สภาพคล่อง เงินเฟ้อที่ไม่คงที่
และการเปลี่ยนใจของผู้ใช้เอง ทุกข้อทำให้ผลจริงแย่กว่าที่เครื่องมือแสดง

## กฎข้อเดียวที่ต้องจำ

**ภาพประกอบทั้ง 11 ภาพถ่ายจากหน้าจอของ v1.7.0 จริงด้วย Playwright และป้ายกำกับ
ทุกช่องคัดมาจาก `index.html` ของรุ่นนั้น** — ไม่ได้เขียนจากความจำ

แปลว่า **เมื่อใดที่ UI เปลี่ยน คู่มือจะผิดทันทีโดยที่ตัวมันเองไม่บอก**
ถ้าปล่อยไว้ ผู้ใช้จะอ่านคำอธิบายของปุ่มที่ไม่มีอยู่แล้ว ซึ่งแย่กว่าไม่มีคู่มือ

เมื่อปล่อยรุ่นใหม่ที่หน้าจอต่างจากเดิม ให้สร้างคู่มือใหม่แล้ววางไว้ที่นี่
**ในชื่อที่มีเลขเวอร์ชันของรุ่นนั้น** และอัปเดตตารางด้านบน — อย่าเขียนทับไฟล์เก่า
เพราะคนที่ยังใช้รุ่นเก่าอยู่ (หรือเปิดไฟล์เคสเก่า) ยังต้องการฉบับที่ตรงกับรุ่นของเขา

**กฎข้อนี้คือเหตุผลที่ไฟล์ 1.0.0 และ 1.4.0 ยังอยู่ในโฟลเดอร์นี้** แม้เล่ม 1.7.0 จะถูกเขียนขึ้นเพื่อ
ใช้แทนทั้งเล่มก็ตาม — ตารางด้านบนทำหน้าที่บอกว่าเล่มไหนคือฉบับปัจจุบัน

**และมีเทสต์บังคับไว้แล้ว:** `tests/unit/app-chrome.test.js` ตรวจว่าลิงก์คู่มือใน footer ของ
`index.html` **ชี้ไปเล่มใหม่สุดใน `docs/`** ไม่ใช่แค่ "ไฟล์ที่ชี้ไปมีอยู่จริง" — เพราะเล่มเก่า
ยังอยู่ในโฟลเดอร์นี้ตามกติกาข้างบน เทสต์ที่เช็คแค่ว่าไฟล์มีอยู่จึงยังเขียวถ้าลิงก์ชี้ไปเล่มเก่า
**วางคู่มือใหม่แล้วลืมแก้ลิงก์ = ชุดเทสต์แดงทันที** ซึ่งเป็นสิ่งที่ตั้งใจให้เกิด
